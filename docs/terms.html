What it is

VidFast launcher is a free browser extension that reads the IMDb page you’re on and opens a matching VidFast link in a new tab. It doesn’t host, stream, upload or download any video, and it doesn’t store any content.

It’s an independent project and isn’t affiliated with, endorsed by or sponsored by IMDb or VidFast. Their names are used only to describe what the extension works with.
