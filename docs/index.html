Install in a minute.

It isn’t on the Chrome Web Store, so it installs the way developers load their own extensions. Works in Chrome, Brave, Edge and Arc on desktop.

Download v1.0.0 15 KB

  1. Unzip it

    Put the vidfast-launcher folder somewhere it can stay. Chrome loads the extension from it.

  2. Open extensions

    Go to chrome://extensions and switch on Developer mode, top right.

  3. Load unpacked

    Click Load unpacked and choose the folder you just unzipped.

  4. Pin and go

    Pin it from the puzzle-piece menu, then click it on any IMDb title.

To update, replace the folder’s files with a newer release and press reload on the extensions page. Your history stays.
