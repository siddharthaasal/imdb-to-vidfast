From an IMDb page to the player in one click.

VidFast launcher reads the title you’re looking at, works out whether it’s a film, a show or a single episode, and opens it in VidFast in the tab next to yours. It remembers your last five, and picks shows up where you left off.

01

Reading the page, carefully.

IMDb doesn’t offer an API for this, so the extension reads the page itself. Every value comes from more than one place, so one markup change on IMDb’s side doesn’t break it.

The title ID

Taken from the URL, so it works on desktop, mobile and regional pages like /fr/title/.

/\/title\/(tt\d{7,})/

What kind of title

Read from the structured data IMDb embeds for search engines, with IMDb’s own page data as a fallback for TV films and shorts.

// JSON-LD @type
Movie     → movie
TVSeries  → series
TVEpisode → episode

Series, season, episode

The series ID comes from page data, then structured data, then the “back to series” link. The numbers fall back to the visible S2.E5 label.

// never the episode’s own ID
seriesId = candidates
  .find(c => c && c !== id)
02

One icon, different jobs.

The toolbar icon changes what it does depending on the page you’re on, and updates as you move between tabs.

Where you areWhat a click does
A movie on IMDbOpens the movie
A show’s main pageOpens S1 E1, or resumes your last episode
An episode pageOpens that exact episode
Any other websiteShows your recent titles
IMDb people, lists, gamesNothing. The icon greys out.

On IMDb a click is already taken, so your recent titles are in the icon’s right-click menu instead.

If the season or episode can’t be read, for example a season listed as “Unknown”, it opens the show at the start and shows a ? on the icon rather than guessing.

03

It remembers where you were.

Every launch is saved in your browser. Nothing leaves it: there’s no server, no account and no analytics.

04

Small on purpose.

About 640 lines of plain JavaScript, HTML and CSS across eight files. Here are a few of the decisions behind it.

No framework, no build step

The folder you load is the source. Edit a file, press reload on the extensions page, done.

A self-contained page reader

The detector runs inside IMDb’s page, where Chrome passes in the function body alone. So it carries no imports, and it’s easy to test in DevTools.

Stale data is ignored

IMDb can change pages without reloading. Any page data whose ID doesn’t match the URL is set aside instead of trusted.

Launches outlive the popup

A popup closes as soon as the new tab takes focus, so it hands the launch to the background worker, which finishes saving it.

One place for the domain

The VidFast address lives in a single file. If it moves, the fix is one line.

Ready for another source

The detector returns a plain { id, type, season, episode } shape, so a second site like TMDB only needs a second detector.

05

Install in a minute.

It isn’t on the Chrome Web Store, so it installs the way developers load their own extensions. Desktop Chrome, or Chromium browsers like Brave, Edge and Arc.

Download v1.0.0 15 KB
  1. Unzip the download somewhere it can stay. Chrome loads the extension from that folder.
  2. Open chrome://extensions and turn on Developer mode. The switch is at the top right.
  3. Click Load unpacked and choose the vidfast-launcher folder.
  4. Pin it from the puzzle-piece menu, then click it on any IMDb title.
